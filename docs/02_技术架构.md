# CourseCompass · 技术架构文档

> 版本 v0.1 · 最后更新：Day 1

---

## 1. 整体架构

```
┌──────────────────────────────────────────────┐
│                   浏览器                       │
│   React SPA (Vite + React Router + Axios)    │
└─────────────────────┬────────────────────────┘
                      │ HTTP / JSON
┌─────────────────────▼────────────────────────┐
│                 Flask 后端                     │
│   路由层 → 业务逻辑层 → 数据访问层(SQLAlchemy) │
└─────────────────────┬────────────────────────┘
                      │
┌─────────────────────▼────────────────────────┐
│          SQLite（本地开发）                     │
│       PostgreSQL（线上部署）                   │
└──────────────────────────────────────────────┘
```

前后端完全分离，通过 `/api/v1/` 接口通信。前端本地开发时用 Vite 代理转发请求，生产环境配置跨域即可。

│   ├── courses.js
│   ├── teachers.js

## 3. 后端模块划分

```
backend/
├── app.py                   # Flask 入口，注册蓝图、CORS、数据库
├── config.py                # 开发/生产环境配置切换
│
├── models/                  # 数据模型（SQLAlchemy ORM）
│   ├── course.py
│   ├── teacher.py
│   ├── comment.py
│   └── credit_rule.py
│
├── routes/                  # 路由蓝图（按功能分组）

│   ├── courses.py
│   ├── teachers.py
│   ├── comments.py
│   └── planner.py
│
├── services/                # 业务逻辑（与路由解耦，方便测试）
│   ├── holland_scorer.py    # Holland 计分 + 类型判断
│   ├── recommender.py       # 规则映射：类型 → 方向 → 课程

│   ├── seed_teachers.json

│

```

## 5. 本地开发运行

### 启动后端

```bash
cd backend
pip install -r requirements.txt
cp .env.example .env          # 填写环境变量
python scripts/import_data.py # 首次运行导入初始数据
flask run --port=5000
```

### 启动前端

```bash
cd frontend
npm install
npm run dev                   # 默认 http://localhost:5173
```

### 前端代理配置（`vite.config.js`）

```js
export default {
  server: {
    proxy: {
      '/api': 'http://localhost:5000'
    }
  }
}
```

### 环境变量

```bash
# backend/.env
FLASK_ENV=development
DATABASE_URL=sqlite:///coursecompass.db
SECRET_KEY=换成随机字符串

# frontend/.env.local
VITE_API_BASE=http://localhost:5000
```

## 7. Git 分支策略

```
main       ← 只放稳定可运行版本，对应线上
dev        ← 日常开发合并目标
feature/xx ← 每人的功能分支，如 feature/quiz-page
```

**合并规则**：提 PR 前本地自测通过 → 发 PR 到 dev → 至少一人 Review → 合并。main 只在 MVP 完成或重要里程碑时从 dev 合并。

### Commit 格式

```
feat:  新增问卷页面
fix:   修复评论提交后列表不刷新的 bug
docs:  更新 README 安装步骤
style: 统一按钮圆角样式
data:  补充课程数据 20 条
```
