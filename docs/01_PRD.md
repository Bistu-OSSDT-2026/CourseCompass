# CourseCompass · PRD 产品需求文档

> 版本 v0.1 · 最后更新：Day 1

---

## 1. 问题陈述

实行完全学分制后，学生需要自行规划修课路径，但面临三个核心障碍：

**信息分散**：课程信息散落在教务系统、专业培养方案、老师个人主页三处，没有统一入口。

**决策盲区**：新生不清楚自己适合哪个发展方向，只能凭感觉或跟风选课。

**经验断层**：选过课的学长学姐的评价和建议无处沉淀，每届重复踩坑。

---

## 2. 目标用户

| 用户群 | 使用场景 | 核心诉求 |
|--------|----------|----------|
| 大一新生 | 入学后首次选课 | "我该选什么方向，从哪里开始" |
| 在校生（大二及以上） | 每学期选课前 | "这门课值不值得选，这个老师怎么样" |
| 有经验的学长学姐 | 想分享选课经验 | "把我踩的坑告诉后来人" |

**核心用户**：大一新生，对完全学分制规则完全不熟悉，需要从零开始规划。

---

## 3. 功能边界

### ✅ 做（MVP 范围内）

- Holland 兴趣测评 → 输出发展方向推荐 + 对应课程列表
- 课程导览：按方向 / 学分 / 类型筛选，关键词搜索
- 教师信息聚合页：姓名、职称、研究方向、开设课程
- 课程匿名评论：难度评分、给分风格、文字建议
- 学分规划器：输入已修学分 → 显示差额 + 推荐补足课程

### ❌ 不做（明确排除）

- 自动抢课 / 模拟选课操作（合规风险）
- 与教务系统实时数据对接（接口不公开）
- 用户社交关系（关注 / 私信 / 主页）
- 神经网络 / LLM 个性化推荐（规则映射替代即可）
- 移动端原生 App（响应式网页覆盖手机场景）
- 后台管理 Web 界面（用命令行脚本代替）

> **原则**：7 天内做不完的功能，统一记录到 GitHub Issues 留待后续迭代，不塞进 MVP。

## 4. 核心流程

### 流程 A：新生首次使用（最重要）

```
进入首页
  → 点击「开始测评」
    → 完成 20 题 Holland 问卷（支持上一题）
      → 提交 → 显示兴趣类型 + 推荐发展方向
        → 点击方向 → 跳转对应课程列表
          → 点击课程 → 查看详情和同学评价
```

### 流程 B：老生查老师信息

```
进入教师列表 → 搜索姓名 / 按院系筛选
  → 点击教师卡片 → 查看详情 + 开设课程
    → 点击课程 → 跳转课程详情
```

### 流程 C：发表课程评论

```
进入课程详情页 → 滚动到评论区
  → 填写：昵称（可匿名）+ 星级 + 文字评价
    → 提交 → 进入审核队列 → 审核通过后展示
```

### 流程 D：学分规划

```
进入学分规划器 → 输入年级 + 各类已修学分
  → 实时显示：各类别差额 + 推荐可补修课程
```

## 5. 关键页面状态

### 问卷页

| 状态 | 触发条件 | 展示内容 |
|------|----------|----------|
| 初始 | 进入页面 | 欢迎语 + 开始按钮 |
| 答题中 | 点击开始 | 题目 + 选项 + 进度条 + 上一题 |
| 提交中 | 点击提交 | Loading（后端计算中） |
| 结果 | 接口返回 | 类型卡片 + 方向推荐列表 |
| 出错 | 接口失败 | 错误提示 + 重试按钮 |

### 课程列表页

| 状态 | 展示 |
|------|------|
| 默认 | 全部课程，按学分降序 |
| 筛选中 | 高亮已选项，结果实时刷新 |
| 搜索 | 匹配课程名 / 教师名，高亮匹配词 |
| 空结果 | 「没有找到相关课程」+ 清空筛选按钮 |
| 加载中 | 骨架屏（Skeleton） |

### 评论区

| 状态 | 展示 |
|------|------|
| 未提交 | 输入框 + 星级选择 + 提交按钮 |
| 提交中 | 按钮 disabled + Loading |
| 提交成功 | 提示「已提交，审核后展示」，表单重置 |
| 提交失败 | 红色错误提示，内容不丢失 |
| 无评论 | 「还没有人评价，来做第一个」 |

---

## 6. 成功标准

| 指标 | 目标值 | 说明 |
|------|--------|------|
| MVP 完成率 | 5 个核心功能全部可用 | 7 天内跑通 |
| 问卷完成率 | 启动后 > 80% 完成 | 题量控制在 20 题以内 |
| 课程数据覆盖 | 本专业全部课程录入 | 手动整理兜底 |
| 评论条数（内测） | 上线首周 > 30 条 | 招募同学试用 |
| GitHub Stars | 上线后 1 个月 > 20 | 推广到校内论坛 |
